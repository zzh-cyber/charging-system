# NO.60 数据库备份 / 恢复 / 权限 / 审计 · 完成说明

## 1. 每日备份（✅ 已完成）

- `mysqldump --single-transaction --no-tablespaces --skip-extended-insert` 生成带日期的备份文件（`charging_system_YYYYMMDD.sql`）
- 备份前 `CHECK TABLE` 做完整性检查
- 备份后逐表核对行数（9 张表），确保备份可用
- 保留全部历史备份（永不删除），并写 `backup/backup.log` 日志

## 2. 配置 / API Key 与数据库分离（✅ 已完成）

- 数据库密码从环境变量 `CHARGING_DB_PASSWORD` 读取，未设置时回退实训默认值
- 不再把明文密码硬编码进代码、提交进 Git

## 3. 权限控制（✅ 已完成）

- 备份目录 `backup/` 设为 `chmod 700`（仅应用账号可读写，其他用户不可）
- 数据库文件由 MySQL（`mysql` 用户）管理；头像目录按需同样收紧权限

## 4. 异常审计

- DAO 层统一捕获查询/事务异常，返回**错误码**（`Protocol::DbError` 等）+ **错误信息**（`m_lastError`）
- 错误信息只含 SQL 错误，**不包含密码或完整 token**
- 事务通过 `runInTransaction` 包装，失败时回滚并记录，死锁/锁等待自动重试

## 5. 恢复演练步骤

1. **停止服务**：`pkill -x charging-server`
2. **恢复**：`mysql -u charging_user -p charging_system < backup/charging_system_YYYYMMDD.sql`
3. **验证**：`SHOW TABLES` 应为 9 张表，逐表核对行数
4. **重启**：`./build/server/charging-server`，确认打印 `数据库结构版本: 2`
